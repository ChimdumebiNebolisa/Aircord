# Aircord Submission Checklist

Nothing in this checklist indicates that a Devpost submission has already been made.

- [ ] Repo is public
- [ ] LICENSE file exists
- [ ] README has judge-facing summary
- [ ] Public demo URL works
- [ ] `/demo-summary.json` works
- [ ] Final snapshot regenerated before recording
- [ ] Vercel deployment refreshed
- [ ] Video under 3 minutes recorded
- [ ] YouTube/Vimeo public link added
- [ ] Devpost draft copied
- [ ] CockroachDB tools selected
- [ ] AWS services selected
- [ ] Architecture diagram included if possible
- [ ] No secrets committed
- [ ] `npm run typecheck` passes
- [ ] `npm run build` passes
- [ ] `python -m pytest backend/tests` passes
